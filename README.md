# QuestFlow

University of Waterloo campus schedule & room-to-room walking assistant.

## Run locally

1. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open http://localhost:3000 in your browser.

> **Note:** Setting `GEMINI_API_KEY` in `.env` is optional — message drafts automatically use built-in templates without it.
